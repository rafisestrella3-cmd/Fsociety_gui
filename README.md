# fsociety-gui

Dashboard de monitoreo de red y consola centralizada de herramientas de seguridad desarrollada en Python. La aplicación integra métricas de sistema en tiempo real, visor de archivos y accesos a utilidades de análisis e inspección de red.

## Descripción General

`fsociety-gui` está diseñada para Un enotno mas cómodo por medio de terminal Una copia de Ede Ui si perome dio ganas de crearlo esta hecho con claude

## Requisitos y Dependencias del Sistema

### Entorno de Ejecución
- **Python**: Versión 3.8 o superior.
- **Sistema Operativo**:Windows

Para que lo botones funcionen Instala esto y si no aparece el programa instala dependencias 
- **Wireshark / TShark**
- **Nmap**
- **Hashcat**
- **Zenmap**
- **Hydra / Netcat**
- **Tor**

Instalar:   python -m pip install PyQt6 psutil pyte
Opcional:   python -m pip install pywinpty     (si falla, no pasa nada)
Ejecutar:   python fsociety_gui.py
